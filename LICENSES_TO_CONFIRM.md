# License choices to confirm before public release

No license has been assigned automatically in this preparation package.
The research team should approve the licensing before publishing the GitHub repository or Zenodo record.

Recommended split:

- **Source code (`code/`)**: MIT License, if the team wants broad reuse with attribution and minimal restrictions.
- **Data, supplementary PDF, and documentation (`data/`, `supplementary/`, `docs/`)**: Creative Commons Attribution 4.0 International (CC BY 4.0), if the team wants reuse with attribution.

Zenodo supports mixed-license uploads, so both licenses can be declared on the same record if the team keeps one reproducibility-package record.

Before release, replace this file with the actual license texts or add explicit `LICENSE_CODE` and `LICENSE_DATA` files.
