## Description
This reproducibility package supports a statistically controlled 270-run comparison of Monte Carlo resampling (MC-R), Latin hypercube resampling (LHS-R), and residual-adaptive Latin hypercube resampling (ALHS-R) for a physics-informed neural network applied to nonlinear shuttlecock flipping dynamics. It contains the statistical supplementary material, complete run-level numerical results, descriptive summaries, experiment-integrity and configuration metadata, and the frozen Python implementation used for the publication experiment. The package corresponds to the manuscript “Sample-Efficient Residual-Adaptive Collocation for Physics-Informed Neural Networks: A 270-Run Study of Shuttlecock Flipping Dynamics.” Experimentally observed shuttlecock trajectories collected for subsequent studies are outside the scope of this deposit and are not included.
